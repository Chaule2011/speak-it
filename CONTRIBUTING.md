# Contributing

Please read [the Code of Conduct](CODE_OF_CONDUCT.md) before participating.

Open an issue for a reproducible problem or proposed improvement. Include the
browser, steps to reproduce, and expected behavior. Never include API keys or
private classroom data.

For changes, create a branch, keep the change focused, and submit a pull
request describing the behavior and how you checked it. Run `npm run build`.
Check both the Gemini and Azure interfaces when changing shared layout or
timeline behavior. Azure checks use your own Speech resource and quota.

Contributions to project code and documentation are made under its MIT
license. Do not contribute assets or code you lack permission to share.
